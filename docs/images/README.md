## 📐 Specifications

### Image Format
- **Format:** PNG (lossless)
- **Color Space:** sRGB
- **Bit Depth:** 24-bit (8 bits per channel)

### Dimensions
- **Hero/Main:** 1920x1080 (16:9)
- **Feature:** 1600x900 or 1200x800
- **Demo:** 1400x800 minimum

### File Size
- **Target:** <500KB per image
- **Maximum:** 1MB per image
- **Optimization:** Use TinyPNG or ImageOptim

## 🎨 Style Guidelines

### Color Scheme
- **Background:** #0a0a0a (dark)
- **Cards:** #1a1a1a (secondary)
- **Accents:** Red (#e63946), Green (#06ffa5), Orange (#f77f00)
- **Text:** White (#ffffff), Gray (#a0a0a0)

### Typography
- **Headings:** Inter, system-ui
- **Body:** Inter, system-ui
- **Monospace:** 'Courier New', monospace

### UI Elements
- Rounded corners (8px)
- Subtle shadows
- Gradient accents
- Clean, professional appearance

## 📸 Capture Instructions

### Browser Setup
1. Open application in Chrome/Firefox
2. Set window to 1920x1080
3. Enable full screen (F11)
4. Zoom: 100%
5. Dark mode enabled

### Screenshot Tools
- **Windows:** Snipping Tool, ShareX
- **macOS:** Screenshot (Cmd+Shift+4)
- **Linux:** Flameshot, GNOME Screenshot

### Post-Processing
1. Crop to relevant content
2. Optimize file size
3. Add subtle drop shadow (optional)
4. Verify text readability
5. Save as PNG

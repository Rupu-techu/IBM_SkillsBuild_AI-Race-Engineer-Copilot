## 🔍 Quick Reference

### Installation
```bash
git clone https://github.com/yourusername/ai-race-engineer-copilot.git
cd ai-race-engineer-copilot
pip install -r requirements.txt
cd frontend && npm install
```

### Running
```bash
# React Frontend
cd frontend && npm run dev

# Python Backend
python examples/analyze_race.py

# Langflow
langflow run
```

### Key Files
- **Main App:** `frontend/src/App.jsx`
- **Race Analyzer:** `src/core/race_analyzer.py`
- **Granite Engine:** `src/ai/granite_engine.py`
- **Langflow Client:** `workflows/langflow_client.py`
